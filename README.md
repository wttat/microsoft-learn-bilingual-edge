# Learn 官方中英对照

一个可直接加载的 Microsoft Edge Manifest V3 插件。打开 Microsoft Learn 文档文章或培训单元时，默认以**左中文、右英文**展示微软已经发布的两个官方版本，每栏独立竖向阅读，滚动任一栏时另一栏同步跟随。

**不自行翻译、不调用 AI、不需要 API 密钥，不将中英文文字的不同标成内容缺陷。无需构建或安装依赖即可使用。**

## 安装

推荐从 [v1.0.4 Release](https://github.com/wttat/microsoft-learn-bilingual-edge/releases/tag/v1.0.4) 下载 `learn-bilingual-edge-v1.0.4.zip` 精简安装包并解压。也可以下载本仓库源码或通过 Git 克隆项目。无需构建。

1. 在 Edge 地址栏打开 `edge://extensions`。
2. 打开页面左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择下载或克隆得到的**项目根目录**。该目录直接包含 `manifest.json`，不要选择它的上一级或 `tests` 子目录。
5. 打开或刷新一篇 Learn 中英文文章，例如 [存储帐户概述](https://learn.microsoft.com/zh-cn/azure/storage/common/storage-account-overview)。

插件更新后，在扩展管理页点击“重新加载”，再刷新已打开的 Learn 网页。扩展刚安装时，已有网页也需要刷新一次。

Release 中的精简包仅包含扩展运行文件和中文说明。先解压到一个独立目录，再加载该目录中的 `manifest.json` 所在文件夹；不能直接加载 ZIP 文件。

### 更新后仍显示旧界面或地址不匹配

如果栏头仍显示“中文 · 官方原文”“英文 · 官方原文”、顶部没有“交换中英位置”，或者“收起 · 返回原页”还在顶部工具栏而不是右下角，当前显示的仍是旧版界面，不是 1.0.4。

1. 打开 `edge://extensions`，确认“Learn 官方中英对照”的版本为 **1.0.4**，并且只启用一个副本。
2. 如果版本不对，停用旧副本，再通过“加载解压缩的扩展”选择**已更新到最新代码、直接包含 `manifest.json` 的项目根目录**。如果此前从 ZIP 解压安装，项目目录的更新不会自动同步到另一个解压目录；也可以重新解压最新的 1.0.4 精简包后加载。
3. 在扩展管理页点击“重新加载”，再刷新 Learn 网页；仍有旧界面时，关闭旧标签页后重新打开文章。

阅读器顶部的“重新读取”只重新获取官方正文，**不会更新扩展代码**，不能替代上述操作。

## 使用

| 操作 | 作用 |
| --- | --- |
| 同步滚动 | 默认开启。使用鼠标滚轮、触控板、滚动条或键盘滚动任意一栏，另一栏跟随；关闭后可分别阅读。 |
| 交换中英位置 | 在“左中文、右英文”和“左英文、右中文”之间切换。整栏标题、正文及原文链接一起移动，保留阅读位置，不重新请求正文；下次打开会记住顺序。 |
| 自动打开 | 默认开启。取消后不再自动展开，但仍可点击页面右下角“中英对照”或扩展图标打开。 |
| 打开官方原文 | 在新标签页打开对应语言的官方页面，保留版本查询参数和初始章节链接。 |
| 重新读取／重试读取官方版本 | 重新并发请求两个官方版本；旧请求被取消，陈旧结果不会覆盖新文章。 |
| 收起 · 返回原页 | 位于阅读器右下角的悬浮按钮，与原页“中英对照”入口使用相同的右下角定位，不随正文滚动。点击恢复原网页及打开前的滚动位置和溢出样式；按 Esc 也可收起，原页右下角入口可重新展开。 |
| 正文内的章节链接 | 在当前栏跳至章节，并在同步开启时对齐另一栏。其他正文链接在新标签页打开。 |

同步、自动打开和左右语言顺序设置仅保存在本机。两栏标题简化为“中文”“英文”，仍可通过各栏的“打开官方原文”链接访问原站。两栏布局始终保持左右排列；窄窗口建议最大化 Edge。代码块和宽表格支持横向滚动。

## 工作方式与边界

- 只请求 `https://learn.microsoft.com/zh-cn/...` 和 `/en-us/...` 的官方 HTML，不使用 iframe，不依赖翻译服务。
- 保留 `view`、`viewFallbackFrom` 等查询参数；章节 hash 用于阅读定位，不发送到服务器。只在读取正文时移除 `accept` 参数，避免得到 Markdown 而非 HTML。带 `data-moniker` 的多版本正文按 `view` 或官方默认版本筛选，不混入其他版本；无法确认或两种语言版本不一致时明确提示。
- 依据真实 Learn 页面的 `main` 内 `.content` 区域和文章类型标记抽取文档正文。培训单元单独提取 `#module-unit-title` 和 `#module-unit-content`，排除单元导航、经验值、学习时长、完成状态及下一单元控件。保留标题、章节、列表、代码、表格与图片，排除站点导航、侧栏目录、反馈和页脚。不抓取整个页面。
- 支持 `conceptual`、`reference`、`dotnet`、`unit` 文档模板，以及 `page_type=learn`、`schema=ModuleUnit` 的培训单元，例如 [GitHub Copilot 用户提示进程流](https://learn.microsoft.com/zh-cn/training/modules/introduction-prompt-engineering-with-github-copilot/3-github-copilot-user-prompt-process-flow)。首页、产品入口、课程／学习路径目录、搜索、问答、其他参考模板、交互式练习等不在支持范围内。遇到不支持的页面，扩展图标会提示，原页仍可正常使用。
- 支持通过官方模块菜单切换单元及浏览器前进／后退等不刷新整页的导航。后台按浏览器提供的当前标签页地址校验请求；切换后可取消旧单元请求，旧结果不会覆盖新正文。
- 同步优先使用两种语言共有的章节 `id`，不以翻译后的标题文字匹配。章节间按高度插值；没有共有锚点时按全文可滚动距离比例同步。章节缺失或顺序不同的部分无法逐段精确对应，也不进行语义差异分析。
- 页面缩放、窗口调整及图片加载引起高度变化时重新计算。没有滚动空间的短文保持在顶部。
- 只有微软已经发布且可确认语言的版本才会显示。HTTP 404、服务器错误、超时、语言标记不一致、不同文章地址或两个版本正文完全相同，都会明确说明；一栏失败不阻止另一栏阅读。
- 为保证后台绝不跟随到其他主机，自动获取不跟随重定向。出现重定向提示时，先点击“打开官方原文”，让浏览器到达最终官方文章地址，再重新对照。这也避免把语言重定向误认为译文。
- 这是静态正文阅读器，不运行官方页面脚本，因此站内交互组件、代码运行按钮、选项卡和视频不提供原站交互；可通过官方原文使用这些功能。官方不同版本可能更新时间不同。

## 安全与隐私

扩展仅申请 `learn.microsoft.com` 主机权限和本机 `storage` 权限，无全站权限、遥测、外发服务、远程脚本或 CDN。后台验证消息来源、当前文章地址和主框架，两个官方请求并发进行，单次读取超时为 20 秒，正文大小上限为 6 MiB。

远程 HTML 先在惰性模板中解析，再按标签和属性白名单重建正文。脚本、事件属性、内联样式、危险 URL、表单和可执行嵌入会被移除。只自动加载 Learn 同源图片，外站图片显示提示；普通外部链接仅在用户点击后打开，并禁用来源信息和新窗口反向访问。

Shadow DOM 隔离阅读器样式；阅读器不删除或替换原网页正文。Learn 原网页本身的脚本和网络行为仍属于原站，不受插件控制。

## 开发与验证

使用插件不需要 Node。运行自动化验证时需要 **Node.js 22 或更新版本**，不需要 `npm install`。

```powershell
node --test tests\core.test.cjs tests\background.test.cjs
node --test tests\browser.test.cjs tests\training.test.cjs tests\navigation.test.cjs
```

浏览器用例会启动独立临时配置目录中的本机 Edge，不使用个人浏览器配置；实际以解压缩扩展加载项目，访问真实 Learn 存储帐户概述、带 `view` 的 .NET 参考文章及 GitHub Copilot 培训单元，通过 Edge 调试协议执行正文净化、双向鼠标滚轮、同步开关、章节定位、图片延迟加载、窗口变化、设置持久化、中英文培训入口、官方菜单切换到总结单元、历史导航、查询参数变化、原页恢复及首页／课程目录不误抓等验证。另在测试浏览器内模拟语言回退、404、同文回退及旧请求延迟返回，验证错误提示和重试恢复。结束后关闭测试浏览器并清理临时配置。网络或组织策略限制可能导致真实浏览器用例失败。

若 Edge 不在标准安装位置：

```powershell
$env:EDGE_PATH = 'D:\你的浏览器路径\msedge.exe'
node --test tests\browser.test.cjs tests\training.test.cjs tests\navigation.test.cjs
```

`tests` 和 `package.json` 仅用于开发，不参与插件运行。运行文件为根目录的 `manifest.json`、`background.js`、`core.js`、`article.js`、`sync.js`、`content.js` 和 `reader.css`。精简 ZIP 仅包含这些运行文件和本说明；执行测试请使用完整项目目录。
